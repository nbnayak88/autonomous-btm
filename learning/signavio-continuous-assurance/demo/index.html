Continuous Assurance Demo: nine audit processes
Illustrative prototype on synthetic data · companion to the SAP Signavio reference architecture
Read this first: this is a prototype built to show the design. It is not SAP Signavio and not an SAP product. All data is synthetic. Each screen names the Signavio component it stands for and its public status (available / beta / roadmap). Confirm status with SAP.
Every number on every screen is computed live in your browser from synthetic event logs (12,000 purchase orders for P2P and 6,000 records for each other process; fixed seeds, so results are identical on each load). Deviations are planted on purpose so the tests have something to find. The other eight processes use invented rates and are for illustration only. "Suggested drivers" use a simple concentration measure, not machine learning. The question box is scripted, not a language model.

# Continuous Process Assurance with SAP Signavio (Procure-to-Pay)

Client-neutral solution architecture for moving SAP audits from periodic, sample-based checks to continuous, AI-assisted process intelligence. Synthetic data only.

- [`lite/`](lite/index.html): core topics only (problem, blueprint, component choices, pipeline, control tests, prototype storyboard, decisions, roadmap, risks) plus the extension to finance, revenue, HR, supply chain, ESG, CX, IT and master-data audits.
- [`full/`](full/index.html): full Paperless Architecture Initiative pack (document, deck, workbook, handbook) with requirements, interfaces, data dictionary, governance and chapter 20 (extending to other audits, 37 sample control tests).

Feature status comes from public SAP material. AI root-cause analysis is beta; agentic risk mining is roadmap, not a commitment. Confirm with the vendor.

Built with the SuccessLabs Academy Paperless Architecture Initiative template.

- [`demo/`](demo/index.html): standalone interactive prototype (synthetic P2P data, process map, variants, conformance, eight control tests, driver analysis, deviation workflow, recommendations, audit landscape). Illustrative prototype, not an SAP product.

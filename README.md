Architecting enterprise transformation through strategy, capabilities, operating models, technology, AI, portfolios, and value realization.

## BTM Gameboard Learning Model

The **Autonomous BTM Gameboard Model** turns transformation learning into outcome-led missions with tangible artifacts and evidence of capability. It adapts the six-part pattern: **Player Identity → Winning Promise → Level Ladder → Mission Design → Reward Engine → Growth Loop**.

Read the [Autonomous BTM Gameboard Model](gameboard_model_autonomous_btm.md) for the full blueprint, eight learning formats, practical transformation examples, a transformation capstone, learning-lab mappings, assessment guidance, and a pilot plan.

### Eight Learning Formats

| Format | Primary purpose | Example BTM use |
|---|---|---|
| Webinar | Awareness and orientation | From Strategy to Outcomes |
| MasterClass | Expert judgement on complex transformation decisions | Transformation Architecture Decision Lab |
| Workshop | Practise one focused method | Outcome-to-Metric Studio |
| Bootcamp | Build connected transformation capability | Enterprise Transformation Architect Bootcamp |
| Hackathon | Solve and demonstrate a transformation challenge | Own the Transformation Outcome |
| 21-day Challenge | Build daily habits around ownership and evidence | Daily Transformation Ownership |
| Sprint | Complete one defined deliverable | Five-Day Transformation Roadmap Sprint |
| SuperClass | Executive framing and enterprise-level judgement | Autonomous Transformation Strategy SuperClass |

A format is not a curriculum by itself. Select formats based on learner intent, depth, and expected output, and assess each format proportionately.

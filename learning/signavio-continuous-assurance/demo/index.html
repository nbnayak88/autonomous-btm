Continuous Assurance Demo: Procure-to-Pay
Illustrative prototype on synthetic data · companion to the SAP Signavio reference architecture
Read this first: this is a prototype built to show the design. It is not SAP Signavio and not an SAP product. All data is synthetic. Each screen names the Signavio component it stands for and its public status (available / beta / roadmap). Confirm status with SAP.
Counts are computed live from 12,000 synthetic purchase orders created in your browser (fixed seed, so they are the same each time). Seeded deviations: 140 after-the-fact orders, 23 duplicate-invoice pairs, 9 segregation-of-duties conflicts. "Suggested drivers" use a simple concentration measure, not machine learning. The question box is scripted, not a language model.
